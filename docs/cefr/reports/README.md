# CEFR Work-Package Reports

Create one report per attempt using `../templates/WORK_PACKAGE_REPORT.md`.
Name it `<WP-ID>-<attempt>.md`; retain past delivered attempts and evidence.

Push reports and their sanitized text evidence on the assigned GitHub task branch. Use `../GITHUB_DELIVERY.md`; keep an evidence index under `../evidence/<WP-ID>/<attempt>/INDEX.md`. Local sandbox paths alone are not deliverables. Return full commit-pinned links after verifying the remote SHA.

`HANDOFF-PREPARATION-001.md` records preparation of the external execution branch. It is not acceptance of unfinished product phases.

Reports document observable engineering work, not hidden model reasoning. No credentials, real user progress, private account details, or absolute owner-machine paths should be published here. See `../../../contracts/DELIVERY_REPORTING.md`.
