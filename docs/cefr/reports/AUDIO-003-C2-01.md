## 3. Changes and rationale

### 3.1 The controller-aware individual reveal

- `js/core/glossary.js` (1 line): the German word span's inline reveal changes from `onclick="this.classList.remove('hidden-word')"` to `onclick="window.app.revealGermanWord(this)"` — the same inline-controller wiring style the same template already uses for `window.app.toggleFavorite(...)`. The article span, the de-context div, and the English span keep their plain reveals: none of them can change `_isRowSpeakable()`, so routing them through the controller would add work with no observable effect (and the membership compare would keep them no-ops anyway).
- `js/core/app.js` (new method `revealGermanWord(el)`, placed directly after `revealAllTable()`):
  1. `scopeBefore = _getSpeakableWords().map(id).join('\u0000')` — snapshot of the single ordered speakable boundary both Start At and playback consume;
  2. `el.classList.remove('hidden-word')` — the reveal itself (unchanged behavior);
  3. `scopeAfter = ...` re-computed from the live DOM;
  4. on `scopeBefore !== scopeAfter`: `stopAudioQueue()` then `_populateStartWordSelect()`.
  This is deliberately the identical before/after membership idiom `revealAllTable()` applies (design symmetry: one reconciliation rule for every German-visibility change), and it re-uses the existing SpeechQueue cancellation path rather than inventing any new teardown — `stopAudioQueue()` → `SpeechQueue.stop()` mints a new generation, so the cancelled session's delayed speak, utterance onend/onerror, watchdog, and no-synthesis timers are all invalidated (verified by the stale-callback phase of test B).
- Requirement mapping: (1) the direct inline reveal is replaced with a controller-aware path; (2) membership change → queue stopped + stale callbacks invalidated through the existing SpeechQueue cancellation + Start At rebuilt AFTER the DOM change, unit order and stable word-id values preserved (they are the boundary's card ids); (3) the newly revealed card immediately appears in Start At (the rebuild is synchronous in the click handler — no debounce exists on this path); (4) selecting it speaks that exact card first (`playAllWords()` resolves the stable id against the same boundary — pre-existing C1 behavior, now with the revealed card actually present in the option list); (5) reveals that do not change `_isRowSpeakable()` are no-ops on the queue (the membership compare is false); (6) phrases/conversations/flashcards/SRS/Favorites/language behavior untouched (their code paths are unchanged).

### 3.2 Preserved behavior and scope discipline

- Write scope = exactly the preferred set: `js/core/glossary.js` (1 line), `js/core/app.js` (+26 lines, one method), `tests/e2e/cefr-audio.spec.js` (+156 lines, the RED commit). No scope expansion was necessary; `js/core/cefr-audio.mjs` was NOT modified (no pure helper justified — see §2 design note).
