## RED methodology note

REVIEW-001 creates a new module. The RED state is the module's absence: at the
tests-only commit the static import fails with ERR_MODULE_NOT_FOUND and the
whole test file fails (0 pass / 1 fail at file level, exit 1), proving the
required behavior does not exist. This follows the AUDIO-001 precedent for
new-module packages. Granular per-case kill attribution comes from the six
mutation probes at the implementation commit.
